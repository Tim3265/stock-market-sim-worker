# Sprint 2 驗證紀錄

> 歷史紀錄：以下為 Sprint 2 當時的驗證內容，現況以 README.md 與 SPEC.md 為準（現為 8 個測試檔、85 項通過，登入／訪客機制已實作）。

使用 Workers 測試執行環境、Miniflare D1 及本機 Wrangler 的隔離資料庫；未連線或修改雲端資料庫。

## 自動測試

- `npm ci` 從 lockfile 安裝後，`npm test`：7 個測試檔、49 項通過。
- 撮合：買／賣價格優先、同價時間順序、掛單價、避開自成交、限價邊界、無對手、部分成交與剩餘取消。
- 交割：買賣方現金與股份總量守恆；中途故意令成交寫入失敗，確認現金、委託、成交和市場版本均回復。
- 並行：同一 request_id 只成交一次；只夠一筆的現金或持股在兩筆併發下最多一筆成功。
- 市場：併發行情讀取只推進一次；15 秒內不重複推進；過很久只推進一輪；無成交不改成交價；資金或庫存不足時停止對應報價。
- 流動性：買一萬股 GG 全數在第一檔成交；買一萬股元智 AI 只成交 510 股，跨多個價位，剩餘取消。
- 遷移：保存舊帳戶、持股與交易；凍結不能超過現金／股份；造市商帳戶 ID 衝突時整個 batch 回復，舊帳戶不被覆寫。

## 真正啟動與瀏覽器操作

使用 `.local-sprint2-proof` 隔離本機資料庫：從空資料庫套用 `database/bootstrap.sql`，套用遷移成功，再次套用回報沒有待執行遷移。啟動本機 Wrangler 後，以 headless Chrome 實際讀取頁面、六檔股票與五檔委託簿，點擊買入與賣出；再讀取 D1 帳戶 API，確認資金及股數與畫面更新，沒有 JavaScript 例外。

本機隔離資料庫只供驗證，不是正式資料庫。尚未對線上 D1、網際網路使用者及多人長時間負載測試；固定玩家帳戶沒有身分驗證，登入仍是後續工作。

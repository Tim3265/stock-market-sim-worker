# 待辦清單（Grooming）

> 2026-11-08 使用者更新：網站採行情、下單與資產分頁，使用簡單帳號登入；不製作報告圖表或書面報告；索引實驗後續以 docs/INDEX-BENCHMARK.md 的 10 萬筆 EXPLAIN QUERY PLAN 對照作為證據（US-25 / S5-3）。遊戲內股價走勢圖保留。舊版以下待辦與估時僅供追溯，應以此決策及程式現況為準。

> 新版設計：帳號密碼登入、每位玩家獨立資產；造市每 15 秒最多一輪且無人時不運作，機器人以低頻真實委託交易；依成交收取 0.0399% 手續費（大樹證券 2.8 折）並向上計至 0.01；舊委託保留原預留資金與免手續費規則。走勢圖只顯示最近六小時實際成交；初期資料不足時不產生虛構走勢。帳號暫不支援密碼重設。

## Sprint 3｜玩家的限價單

**目標**：玩家可以掛單、排隊、部分成交、取消；資金與持股凍結正確。

本版實作限價委託、查詢、取消，以及造市商重新報價後與既有委託的撮合；圖表由 Sprint 4 提前，顯示最近六小時最多 500 筆真實成交。行情、持股、交易與委託畫面使用綽號。尚未部署雲端或實測多人遠端；畫面目前仍固定示範帳戶，不等於已完成多人切換。

後續修正：以頁面內下單視窗取代瀏覽器原生 prompt，六檔股票各自顯示獨立走勢圖；無成交或僅一筆成交時說明資料不足，不憑空生成歷史價格。前端每 5 秒輪詢 `/api/live`（每檔最近 100 筆成交）與 `/api/index`（指數歷史 500 筆）。

## 建議順序

```
Sprint 1（重構 + 測試）
  → Sprint 2（委託簿 + 造市商）
  → Sprint 3（玩家限價單）
  → Sprint 4（其他機器人 + 圖表 + 報表）
  → Sprint 5（交付）
```

**理由**：先把程式拆乾淨、測試補起來，再動撮合。
撮合是整個專案最容易出錯的地方，沒有測試會改到崩潰。

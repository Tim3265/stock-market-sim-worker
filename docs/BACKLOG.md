## Sprint 3｜限價單

**目標**：支援掛單、自動成交、取消。資金與持股要凍結。

| ID | 工作 | 為什麼 | 估時 | 依賴 |
|---|---|---|---|---|
| S3-1 | `orders` 表 + 狀態機 | 委託生命週期 | 2h | S1-6 |
| S3-2 | `accounts.frozen_cash`、`holdings.frozen_shares` | 掛單要先扣住 | 2h | S3-1 |
| S3-3 | 下限價單 API | 掛單 | 2h | S3-2 |
| S3-4 | 觸價撮合（成交時套用衝擊） | 自動成交 | 3h | S3-2 |
| S3-5 | 取消委託並釋放凍結 | 完整生命週期 | 2h | S3-2 |
| S3-6 | 前端「我的委託」列表 | 看得到＝可 demo | 2h | S3-3 |
| S3-7 | 測試：掛單、成交、取消、凍結正確 | 交易一致性 | 3h | S3-5 |

**驗收**：掛一張低於市價的買單 → 現金被凍結 → 價格下跌觸及 → 自動成交 → 凍結解除、持股增加。

> ⚠️ 若時間不足，Sprint 3 可整段砍掉，只留市價單。規格已把限價單列為 P1。

## 建議順序

```
S1-3 → S1-8（重構 + 測試）
  → S2（市場會動）
  → S3（限價單，可砍）
  → S4（多人）
  → S5（交付）
```

**理由**：先讓程式好改，再加功能。Sprint 2 會大量動到價格邏輯，沒有先重構會很難收尾。

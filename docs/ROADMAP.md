# Roadmap — 股市模擬 v1.0

對照台股主流看盤下單軟體（元大投資先生、富邦、群益看盤、永豐 XQ）的功能，
只保留「符合我們委託簿機制」的項目。UI 像素風重做排最後。

## 已實作
- 六檔行情 + 近 6 小時走勢圖、六檔加權指數（基期 1000）
- 委託簿撮合：價格優先 / 時間優先、部分成交、IOC 市價單、限價單掛簿
- 漲跌停 ±10%（當日參考價、台北時間換日）
- 四種機器人帳戶（造市商 / 動能 / 價值 / 恐慌）
- 訪客一鍵登入（暱稱即可），初始資金 = 市場總市值 / 1000
- 大樹證券手續費 2.8 折（0.0399%），當沖開放，T+0 即時交割
- 十檔盤口（depth 可調 1–20）、成交明細、交易紀錄篩選分頁、排行榜
- 有人瀏覽時 15 秒 tick，無人時靜止（省 Workers/D1 免費額度）

## 缺少、值得加（依優先級）
1. **自選股清單** — 本地儲存關注的股票，快速切換（軟體都有）
2. **更多盤口深度** — 已完成：十檔盤口（depth 可調）、造市商每邊五層
3. **技術指標** — MA5/MA20、KD、MACD 疊在走勢圖上（純前端計算即可）
4. **到價警示** — 設定價格條件，觸發時本地通知（不寫 DB，省額度）
5. **即時未實現損益** — 持股按現價浮動盈虧（已有，補 UI 即時跳動）
6. **K 線圖** — 分K（每 tick 一根）與日K 切換
7. **成交量柱狀圖** — 每 tick 成交量
8. **籌碼/機器人動向** — 公開各機器人持倉變化（模擬特色，軟體沒有）
9. ~~歷史資料匯出 — CSV 下載自己的交易紀錄~~（已實作：`/api/trades/export`）
10. **T+2 式延遲交割（選做）** — 把「凍結資金」改成成交後 N 分鐘才扣款，對玩家更好懂；工程量大，排後面

## 不做（不符合我們機制或額度）
- WebSocket 即時推播（免費版 Workers 不適合長連線，輪詢 15 秒即可）
- 信用/融資融券、真實基本面財報、三大法人籌碼（我們是六檔虛擬市場）
- 行動 App、語音下單、程式交易 API

## 流程
本地 wrangler dev 開發 → branch → PR → CI → merge；全部完成後才部署 Cloudflare。
UI（電玩像素風）最後統一重做並反覆迭代。
